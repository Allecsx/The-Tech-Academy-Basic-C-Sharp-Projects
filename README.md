# The Tech Academy Basic C-Sharp Projects

This repository serves as a complete log of my C# and .NET Framework learning journey, organizing everything from my daily coding practice to full-scale applications.


## Repository Structure

* **Coding Assignments:** Over 30 targeted mini-projects designed to master daily programming concepts. These cover string and array manipulations, custom logic methods, structures, enums, exception handling with Try/Catch, lambda expressions, and core Object-Oriented Programming (OOP) principles like inheritance and polymorphism.

* **Featured Applications:** Full-scale web and console apps built to practice real-world software architecture and database integrations.



## Projects:

* [Car Insurance](./Carinsurance/)
* [Twenty One Game](./TwentyOne/)


### Car Insurance
An ASP.NET MVC web platform designed to automate premium calculations. The application collects user background information and vehicle specifications through an interactive form, then runs this data through a custom business logic engine to generate a monthly rate. It features a separate administrator panel that gives staff members a clean overview of all active submissions.


### Twenty One Game
A console-based card game that implements the core mechanics of traditional Blackjack. This project was built to master advanced object-oriented design patterns, leveraging interfaces, inheritance, and enums to manage the game flow, deck shuffling, and automated dealer rules. It also handles edge cases with exception handling and logs session history using file I/O operations.
